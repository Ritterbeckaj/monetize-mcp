# Monetize MCP — the free toolkit that sells your digital products

Eight deterministic tools to price, package, launch and run passive income from any digital product — including your own MCPs. **Free forever (MIT).**

## What's inside

| Tool | What it does |
|---|---|
| `brainstorm_monetization_models` | Ranks 8 models (one-time, tiers, subscription, open-core, bundle, license, course, affiliate) with effort + price range |
| `pricing_strategy` | Recommended price + Good/Better/Best tiers, anchoring rules, break-even sanity check |
| `revenue_projection` | Price × units × fees table + monthly-recurring math |
| `listing_copy` | Name/tagline/description/SEO for a Gumroad/Etsy listing |
| `pricing_page` | Ready-to-publish markdown pricing page |
| `launch_plan` | Day-0 → Week-4 go-to-market checklist |
| `free_platforms_playbook` | Free distribution channels per product type with posting cadence |
| `maintenance_loop` | Weekly/monthly/quarterly passive cadence |

## Install (same as every MCP)

```bash
cd monetize-mcp && npm install
```

```json
{
  "mcp": { "servers": { "monetize": { "type": "local", "command": ["node", "/absolute/path/to/index.js"] } } }
}
```

## Example prompts

- *"Brainstorm ways to monetize my 12-tool strategy MCP for indie hackers"*
- *"Price my LeadGen pack for a small audience"* → `pricing_strategy`
- *"Project revenue at $29 with 30 sales/month"* → `revenue_projection`
- *"Write the Gumroad listing for FactCheck MCP"* → `listing_copy`
- *"Launch plan for my Toolkit bundle, soft launch"* → `launch_plan`

## Why it's free

It's the funnel: it sells the other packs (StrategyBrain Pro, FactCheck, LeadGen) better than any ad. If it made you money, tell one person — that's the whole ask.
